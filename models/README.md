# Voice Doctor AI local model artifacts
No model binaries are committed here. Every future model pack requires: canonical source/revision, license text and commercial redistribution approval, original and converted SHA-256, exact byte count, model format, tokenizer, language capability, Android ABI/runtime version, and successful measured phone load.

Allowed initial languages: en and te only. Gemma 3 weights require Gemma terms; a file renamed `.litertlm` does not become a valid LiteRT-LM artifact. Whisper GGML, E5 ONNX and Telugu TTS licenses must be reviewed individually. Reject unsigned/untrusted model packs.
